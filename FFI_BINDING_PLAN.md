# Rust FFI Binding Integration Plan

## Overview
This plan outlines the integration of Rust-based system input functionality (hotkeys, clipboard, key simulation) into the existing Go/Fyne application using Foreign Function Interface (FFI) and cbindgen.

## Problem Statement
The current Go implementation has limitations with three critical libraries:
1. **golang.design/x/hotkey** - Global hotkey registration
2. **golang.design/x/clipboard** - Clipboard management
3. **github.com/go-vgo/robotgo** - Keyboard simulation

These will be replaced with a Rust FFI library that provides more reliable cross-platform functionality.

### FFI Type Definitions (ffi_types.rs)
```rust
use std::ffi::{CStr, CString};
use std::os::raw::{c_char, c_int, c_void};

/// Opaque pointer types for passing between C and Rust
pub type HotkeyManagerHandle = *mut c_void;
pub type ClipboardHandle = *mut c_void;
pub type SimulatorHandle = *mut c_void;

/// Error codes
#[repr(C)]
pub enum FFIErrorCode {
    Success = 0,
    NullPointer = -1,
    InitFailed = -2,
    InvalidArgument = -3,
    OperationFailed = -4,
}

/// Thread-safe error storage
use once_cell::sync::OnceCell;
use parking_lot::Mutex;

static LAST_ERROR: OnceCell<Mutex<Option<String>>> = OnceCell::new();

pub fn set_last_error(err: String) {
    let error_store = LAST_ERROR.get_or_init(|| Mutex::new(None));
    *error_store.lock() = Some(err);
}

pub fn take_last_error() -> Option<String> {
    let error_store = LAST_ERROR.get_or_init(|| Mutex::new(None));
    error_store.lock().take()
}

/// Helper: Convert C string to Rust String
pub unsafe fn c_str_to_string(c_str: *const c_char) -> Result<String, &'static str> {
    if c_str.is_null() {
        return Err("Null pointer");
    }
    CStr::from_ptr(c_str)
        .to_str()
        .map(|s| s.to_string())
        .map_err(|_| "Invalid UTF-8")
}

/// Helper: Convert Rust String to C string (caller must free)
pub fn string_to_c_str(s: String) -> *mut c_char {
    match CString::new(s) {
        Ok(c_string) => c_string.into_raw(),
        Err(_) => std::ptr::null_mut(),
    }
}
```

### FFI Hotkey Implementation (ffi_hotkey.rs)
```rust
use std::os::raw::{c_char, c_int, c_void};
use std::ffi::CStr;
use std::sync::Arc;
use parking_lot::Mutex;
use super::ffi_types::*;
use crate::core::hotkeys::HotkeyManager;

/// Create new hotkey manager
#[no_mangle]
pub unsafe extern "C" fn myreviser_hotkey_manager_new() -> HotkeyManagerHandle {
    // Note: We need a simplified version without config/revision queue
    // This will be a basic hotkey listener with callback support
    let manager = Box::new(SimpleHotkeyManager::new());
    Box::into_raw(manager) as HotkeyManagerHandle
}

/// Register a hotkey
#[no_mangle]
pub unsafe extern "C" fn myreviser_hotkey_register(
    handle: HotkeyManagerHandle,
    binding: *const c_char,
    action: *const c_char,
    callback: extern "C" fn(*const c_char),
) -> c_int {
    if handle.is_null() || binding.is_null() || action.is_null() {
        set_last_error("Null pointer provided".to_string());
        return FFIErrorCode::NullPointer as c_int;
    }

    let manager = &mut *(handle as *mut SimpleHotkeyManager);

    let binding_str = match c_str_to_string(binding) {
        Ok(s) => s,
        Err(e) => {
            set_last_error(format!("Invalid binding: {}", e));
            return FFIErrorCode::InvalidArgument as c_int;
        }
    };

    let action_str = match c_str_to_string(action) {
        Ok(s) => s,
        Err(e) => {
            set_last_error(format!("Invalid action: {}", e));
            return FFIErrorCode::InvalidArgument as c_int;
        }
    };

    if let Err(e) = manager.register(binding_str, action_str, callback) {
        set_last_error(format!("Registration failed: {}", e));
        return FFIErrorCode::OperationFailed as c_int;
    }

    FFIErrorCode::Success as c_int
}

/// Start listening for hotkeys
#[no_mangle]
pub unsafe extern "C" fn myreviser_hotkey_start(handle: HotkeyManagerHandle) -> c_int {
    if handle.is_null() {
        return FFIErrorCode::NullPointer as c_int;
    }

    let manager = &mut *(handle as *mut SimpleHotkeyManager);

    if let Err(e) = manager.start() {
        set_last_error(format!("Failed to start: {}", e));
        return FFIErrorCode::OperationFailed as c_int;
    }

    FFIErrorCode::Success as c_int
}

/// Stop listening
#[no_mangle]
pub unsafe extern "C" fn myreviser_hotkey_stop(handle: HotkeyManagerHandle) -> c_int {
    if handle.is_null() {
        return FFIErrorCode::NullPointer as c_int;
    }

    let manager = &mut *(handle as *mut SimpleHotkeyManager);

    if let Err(e) = manager.stop() {
        set_last_error(format!("Failed to stop: {}", e));
        return FFIErrorCode::OperationFailed as c_int;
    }

    FFIErrorCode::Success as c_int
}

/// Free hotkey manager
#[no_mangle]
pub unsafe extern "C" fn myreviser_hotkey_manager_free(handle: HotkeyManagerHandle) {
    if !handle.is_null() {
        let _ = Box::from_raw(handle as *mut SimpleHotkeyManager);
    }
}

/// Get last error message
#[no_mangle]
pub unsafe extern "C" fn myreviser_hotkey_get_error() -> *const c_char {
    match take_last_error() {
        Some(err) => string_to_c_str(err),
        None => std::ptr::null(),
    }
}

/// Free error string
#[no_mangle]
pub unsafe extern "C" fn myreviser_free_string(s: *mut c_char) {
    if !s.is_null() {
        let _ = CString::from_raw(s);
    }
}
```

### FFI Clipboard Implementation (ffi_clipboard.rs)
```rust
use std::os::raw::{c_char, c_int};
use super::ffi_types::*;
use crate::core::clipboard::ClipboardManager;

#[no_mangle]
pub unsafe extern "C" fn myreviser_clipboard_new() -> ClipboardHandle {
    match ClipboardManager::new() {
        Ok(clipboard) => Box::into_raw(Box::new(clipboard)) as ClipboardHandle,
        Err(e) => {
            set_last_error(format!("Failed to create clipboard: {}", e));
            std::ptr::null_mut()
        }
    }
}

#[no_mangle]
pub unsafe extern "C" fn myreviser_clipboard_get_text(handle: ClipboardHandle) -> *mut c_char {
    if handle.is_null() {
        set_last_error("Null clipboard handle".to_string());
        return std::ptr::null_mut();
    }

    let clipboard = &*(handle as *mut ClipboardManager);

    // Create a simple runtime for async operation
    let rt = tokio::runtime::Runtime::new().unwrap();
    match rt.block_on(clipboard.get_text()) {
        Ok(text) => string_to_c_str(text),
        Err(e) => {
            set_last_error(format!("Failed to get text: {}", e));
            std::ptr::null_mut()
        }
    }
}

#[no_mangle]
pub unsafe extern "C" fn myreviser_clipboard_set_text(
    handle: ClipboardHandle,
    text: *const c_char,
) -> c_int {
    if handle.is_null() || text.is_null() {
        return FFIErrorCode::NullPointer as c_int;
    }

    let clipboard = &*(handle as *mut ClipboardManager);

    let text_str = match c_str_to_string(text) {
        Ok(s) => s,
        Err(e) => {
            set_last_error(format!("Invalid text: {}", e));
            return FFIErrorCode::InvalidArgument as c_int;
        }
    };

    let rt = tokio::runtime::Runtime::new().unwrap();
    match rt.block_on(clipboard.set_text(text_str)) {
        Ok(_) => FFIErrorCode::Success as c_int,
        Err(e) => {
            set_last_error(format!("Failed to set text: {}", e));
            FFIErrorCode::OperationFailed as c_int
        }
    }
}

// Similar implementations for save/restore...

#[no_mangle]
pub unsafe extern "C" fn myreviser_clipboard_free(handle: ClipboardHandle) {
    if !handle.is_null() {
        let _ = Box::from_raw(handle as *mut ClipboardManager);
    }
}
```

## Go CGO Wrapper Implementation

### internal/input/ffi_hotkeys.go
```go
package input

/*
#cgo CFLAGS: -I${SRCDIR}/../../rust-ffi
#cgo linux LDFLAGS: -L${SRCDIR}/../../lib -lmyreviser_ffi -ldl -lm
#cgo darwin LDFLAGS: -L${SRCDIR}/../../lib -lmyreviser_ffi -framework CoreFoundation -framework Security
#cgo windows LDFLAGS: -L${SRCDIR}/../../lib -lmyreviser_ffi -lws2_32 -luserenv -lbcrypt

#include <stdlib.h>
#include "bindings.h"

// Callback wrapper - Go can't pass Go functions to C directly
extern void hotkeyCallbackWrapper(char* action);
*/
import "C"
import (
    "fmt"
    "sync"
    "unsafe"

    "github.com/paradoxe35/myreviser-go/internal/logger"
)

// FFIHotkeyManager wraps the Rust FFI hotkey manager
type FFIHotkeyManager struct {
    mu       sync.RWMutex
    handle   C.HotkeyManagerHandle
    handlers map[string]func()
}

// NewFFIHotkeyManager creates a new FFI-based hotkey manager
func NewFFIHotkeyManager() (*FFIHotkeyManager, error) {
    handle := C.myreviser_hotkey_manager_new()
    if handle == nil {
        return nil, fmt.Errorf("failed to create hotkey manager")
    }

    return &FFIHotkeyManager{
        handle:   handle,
        handlers: make(map[string]func()),
    }, nil
}

// RegisterHandler registers a handler for a hotkey action
func (h *FFIHotkeyManager) RegisterHandler(binding, action string, handler func()) error {
    h.mu.Lock()
    defer h.mu.Unlock()

    h.handlers[action] = handler

    cBinding := C.CString(binding)
    cAction := C.CString(action)
    defer C.free(unsafe.Pointer(cBinding))
    defer C.free(unsafe.Pointer(cAction))

    result := C.myreviser_hotkey_register(
        h.handle,
        cBinding,
        cAction,
        C.hotkeyCallbackWrapper,
    )

    if result != 0 {
        errMsg := C.myreviser_hotkey_get_error()
        if errMsg != nil {
            defer C.myreviser_free_string(errMsg)
            return fmt.Errorf("registration failed: %s", C.GoString(errMsg))
        }
        return fmt.Errorf("registration failed with code %d", result)
    }

    return nil
}

// Start starts listening for hotkeys
func (h *FFIHotkeyManager) Start() error {
    result := C.myreviser_hotkey_start(h.handle)
    if result != 0 {
        return fmt.Errorf("failed to start hotkey manager")
    }
    return nil
}

// Stop stops listening for hotkeys
func (h *FFIHotkeyManager) Stop() error {
    result := C.myreviser_hotkey_stop(h.handle)
    if result != 0 {
        return fmt.Errorf("failed to stop hotkey manager")
    }
    return nil
}

// Close frees the hotkey manager resources
func (h *FFIHotkeyManager) Close() {
    if h.handle != nil {
        C.myreviser_hotkey_manager_free(h.handle)
        h.handle = nil
    }
}

// Global callback handling
var globalHotkeyManager *FFIHotkeyManager

//export hotkeyCallbackWrapper
func hotkeyCallbackWrapper(action *C.char) {
    if globalHotkeyManager == nil {
        return
    }

    actionStr := C.GoString(action)

    globalHotkeyManager.mu.RLock()
    handler, exists := globalHotkeyManager.handlers[actionStr]
    globalHotkeyManager.mu.RUnlock()

    if exists && handler != nil {
        go handler() // Run in goroutine to avoid blocking
    } else {
        logger.Warn("No handler for action", "action", actionStr)
    }
}
```

```go
        return fmt.Errorf("failed to simulate select all")
    }
    return nil
}

func (s *FFIKeySimulator) Copy() error {
    result := C.myreviser_simulate_copy(s.handle)
    if result != 0 {
        return fmt.Errorf("failed to simulate copy")
    }
    return nil
}

func (s *FFIKeySimulator) Paste() error {
    result := C.myreviser_simulate_paste(s.handle)
    if result != 0 {
        return fmt.Errorf("failed to simulate paste")
    }
    return nil
}

func (s *FFIKeySimulator) Close() {
    if s.handle != nil {
        C.myreviser_simulator_free(s.handle)
        s.handle = nil
    }
}
```

## Build Process

### 1. Build Rust FFI Library
```bash
# Navigate to rust-ffi directory
cd rust-ffi

# Build for current platform (development)
cargo build --release

# The library will be in target/release/
# Copy to lib/ directory
cp target/release/libmyreviser_ffi.so ../lib/  # Linux
cp target/release/libmyreviser_ffi.dylib ../lib/  # macOS
cp target/release/myreviser_ffi.dll ../lib/  # Windows

# bindings.h is generated automatically during build
cp bindings.h ../rust-ffi/
```

### 2. Build Go Application
```bash
# From project root
CGO_ENABLED=1 go build -o bin/myreviser .
```

### 3. Makefile Integration
```makefile
.PHONY: build-rust build-go build clean

# Build Rust FFI library
build-rust:
	cd rust-ffi && cargo build --release
	mkdir -p lib
	cp rust-ffi/target/release/libmyreviser_ffi.* lib/ 2>/dev/null || true
	cp rust-ffi/bindings.h rust-ffi/

# Build Go application
build-go:
	CGO_ENABLED=1 go build -ldflags "-s -w" -o bin/myreviser .

# Build everything
build: build-rust build-go

# Clean build artifacts
clean:
	rm -rf rust-ffi/target
	rm -rf lib/*
	rm -rf bin/*
	rm -f rust-ffi/bindings.h
```

## Cross-Platform Considerations

### Linux
- Requires X11 development libraries
- Link flags: `-ldl -lm -lpthread`
- Shared library: `libmyreviser_ffi.so`

### macOS
- Requires CoreFoundation framework
- Link flags: `-framework CoreFoundation -framework Security`
- Shared library: `libmyreviser_ffi.dylib`

### Windows
- Requires Windows SDK
- Link flags: `-lws2_32 -luserenv -lbcrypt`
- Shared library: `myreviser_ffi.dll`

## Advantages of This Approach

1. **Better Cross-Platform Support**: Rust crates (rdev, arboard, enigo) are more mature
2. **Performance**: Native Rust is faster than Go for system-level operations
3. **Memory Safety**: Rust's guarantees prevent common C/FFI bugs
4. **Maintainability**: Separate concerns (Rust for system, Go for UI)
5. **Reusability**: Rust FFI lib can be used by other projects

## Potential Challenges & Solutions

### Challenge 1: Callback Handling
**Problem**: C can't directly call Go functions
**Solution**: Use gateway function pattern (hotkeyCallbackWrapper)

### Challenge 2: Async Operations
**Problem**: Rust uses async/await, C doesn't
**Solution**: Create blocking wrappers with `tokio::runtime::Runtime`

### Challenge 3: Memory Management
**Problem**: String ownership across FFI boundary
**Solution**: Explicit free functions for C-allocated strings

### Challenge 4: Error Propagation
**Problem**: Rust Result<T,E> doesn't map to C
**Solution**: Return error codes + thread-local error storage
